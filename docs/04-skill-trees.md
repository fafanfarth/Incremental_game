# 04. スキルツリー

## 4.1 共通フレーム

各ステージに **専用のスキルツリー** を持ち、**そのステージの通貨でのみ** 開放できる。
ツリーは 3つのブロックで構成される。

```
  ┌─ 本編 T1〜T6 ─────────────────────┐
  │  A 単価 / B 頻度 / C 自動化 / D 固有  │  4系統 × 6段 = 24ノード
  └──────────────┬───────────────────┘
                 │  全系統の T4 以上を1つ以上所持で解放
        ┌────────▼────────┐
        │  T7【看守への賄賂】 │  1,000,000 ＝ ステージクリア
        └────────┬────────┘
                 │  購入すると出現
  ┌──────────────▼───────────────────┐
  │  継承 L1〜L4                        │  次のステージ以降に効く
  │  L1 300万 / L2 2,000万 / L3 1億 / L4 5億 │  通貨はこの棟のもの
  └──────────────────────────────────┘
```

| 系統 | 役割 | 色 |
|---|---|---|
| **A 単価** | 1回の獲得量を増やす | 赤 |
| **B 頻度** | 稼ぐ回数・速度を増やす | 青 |
| **C 自動化** | 手を離しても回るようにする | 緑 |
| **D 固有** | そのステージ固有のギミックを操作する | 紫 |
| **L 継承** | **次のステージ以降** を強化する（賄賂購入後） | 金 |

### コスト階梯（全ステージ共通）

| 段 | コスト | 想定到達 | 意味 |
|---|---|---|---|
| T1 | 50 | 開始 1分 | 最初の手応え |
| T2 | 250 | 3分 | 選択の発生（どの系統から伸ばすか） |
| T3 | 1,200 | 8分 | 自動化の到達点（C系統） |
| T4 | 6,000 | 15分 | 放置が成立する |
| T5 | 30,000 | 25分 | 倍率がかかり始める |
| T6 | 150,000 | 35分 | **全部は買えない**。取捨選択の山場 |
| **T7** | **1,000,000** | 35〜40分 | **【賄賂】＝ クリア** |
| L1 | 3,000,000 | クリア後 10分 | 継承の入口 |
| L2 | 20,000,000 | クリア後 40分 | 次の棟のギミックに干渉する |
| L3 | 100,000,000 | クリア後 3時間 | 全ステージ共通の倍率 |
| L4 | 500,000,000 | クリア後 10時間 | **密輸ルート開通**（R-12） |

- 本編ツリー（T1〜T6）の総額 = **750,000**
- T7 と合わせ、クリアまでの生涯獲得額は **約 1,750,000** が標準ルート
- T6 の 4ノードは全買い前提にしない。1〜2個買って T7 へ走り抜けるのが最短
- **継承ツリー（L1〜L4）の総額 = 6億2,300万**。本編の 350倍。
  ここがクリア後の長期目標になる（05章 5.9）

### 解放ルール
- 同一系統は **上から順** にのみ解放可能（T3 を買うには T2 が必要）
- 系統をまたぐ前提条件を各ステージに 1〜2本だけ張り、横断を促す
- **T7【賄賂】の解放条件**: 4系統すべてで T4 以上を1つ以上所持していること
  （＝1系統だけ伸ばした偏りプレイでのクリアを防ぎ、全ギミックに触れさせる）
- **払い戻し（リスペック）は無し**。ツリーはリセットされないため（R-03）、
  買い間違いは恒久的に残る。ただし罠ノードは作らない（05章 5.10-2）ので損は生じない

| S5-D6 | T6 | 同期 | 時計塔の掌握 | 150,000 | 倍率の底 4^(k−1) → **5^(k−1)**（5本同期で ×625） |

> **横断前提**: S5-B3 には S5-B1 が必要（数値が見えないと周期は組めない）。
> S5-C3 には S5-B1 が必要。S5-D6 には S5-B6 が必要。
>
> **バランス注意**: このステージの伸びは「基礎搬出量 B」×「平均倍率 E[M]」の積で決まる。
> A系統が B を、B・D系統が E[M] を伸ばす。
>
> **E[M] の理論上限は 5本すべてを同じ周期に寄せた場合**（d=0.40 で 102.4）だが、
> これには **決して到達させない**。周期の設定範囲を広げるのは S5-D3（±4）のみで、
> 拡張後も **衛兵A の上限 10 と 衛兵E の下限 12 は重ならない** ためである。
>
> | 状態 | 最良構成 | E[M] | 理論上限比 |
> |---|---|---|---|
> | 範囲拡張なし | 6, 6, 6, 12, 24 | 40.7 | 40% |
> | S5-D3 取得後 | 10, 10, 10, 10, 20 | 64.2 | 63% |
> | ＋ S5-D2（d=0.50） | 同上 | 80.2 | 63% |
>
> 到達できるのは常に **「4本＋1本の 1:2 構成」** まで。
> 最後の1本が絶対に噛み合わないことが、クリア後も構成を探し続ける理由になる。
> **他のスキルや継承ノードで周期範囲を広げてはならない**（S4-L2 は窓幅のみ）。
> 構成の評価は `docs/tools/sync_sim.py` で確認できる。

### 4.7.2 継承ツリーの設計原則

1. **効果は必ず「次のステージ以降」にのみ及ぶ**。現在の棟には一切効かない
   → 「前の棟で稼ぐ理由」を構造的に作るため
2. **L1・L3 は全ステージ共通の汎用強化**、**L2 は次の棟のギミックへの直接干渉**
   → L2 だけが「この棟 → あの棟」という specific な繋がりを演出する
3. **L4 は全ステージ共通で密輸ルート**（R-12）。5棟すべて開通が最終目標
4. 順番に買う必要がある（L1 → L2 → L3 → L4）

### 4.7.8 継承ツリーの到達順（想定）

プレイヤーが実際に継承ノードを買っていく順序は、棟の進行とは一致しない。

| 時期 | 典型的な行動 |
|---|---|
| 棟2をプレイ中 | 廊下から棟1に戻り、S1-L1（300万）を買う。棟2の手動が +25% される |
| 棟3をプレイ中 | 棟1・棟2 が放置で貯まっており、S1-L2 / S2-L1 を買う |
| 棟4をプレイ中 | S3-L2（賭場の顔）で医務棟の汚染を半減させる ＝ 効果を実感しやすい山場 |
| 棟5をプレイ中 | S4-L2 で衛兵の窓幅を広げ、同期している時間そのものを延ばす |
| エンディング後 | 全棟を回って L3・L4 を埋めていく。密輸ルート5本開通が最終目標 |

**設計上の注意**: 棟2をプレイ中に S1-L1 を買える（＝300万を棟1で貯められる）
ことが、この仕組みが機能するかの分水嶺になる。棟1をクリアした時点の CPS は
約 5,000/秒 なので、放置 10分で到達する。**Phase 1 の合格条件に含めること。**

## 4.8 周回と永久スキル表について

本章で定義したツリー（本編 T1〜T6・【賄賂】T7・継承 L1〜L4）は、
**すべて周回（記録抹消）でリセットされる**。

周回をまたいで残るのは **永久スキル表** だけであり、
その定義は [08章](08-prestige-and-permanent-skills.md) に置く。
初版にあった「NG+ メダルツリー」は永久スキル表に統合され、廃止された。

| 旧 NG+ ノード | 統合先（08章） |
|---|---|
| 記憶の継承 | P-A1 既視感 / P-A2 手順の記憶 |
| 早送り | P-E1 早送り |
| 賄賂の値切り | P-A3 顔なじみ |
| 二重生活 | P-C3 使い走り |
| 死線（Lethal） | P-E3 賭けの記録 → タイムアタック（09章） |

**永久スキルがこの章のツリーを強化する際の禁止事項**（08章 8.4 と同一）:

- ステージの対抗ギミック（03章 3.6）を無効化してはならない
- **時計塔の周期設定範囲を広げてはならない**（4.6 の注記。永久スキルでも同様）
