# 13. 実機確認とフォント選定

Phase 1 の画面を **iPhone に入れて確かめる**ための手順。
ビルドは macOS でしか行えないため、この章はそちらで実行する作業の説明になる。

## 13.1 まず解決した問題：日本語が豆腐になる

**Godot 4 の既定フォント（Open Sans）に CJK は含まれない。**
本作の UI は全て日本語なので、フォントを同梱しないと実機で
文字が全て □ になる。エディタでは OS のフォントで補完されて気づかないことがある。

対応済み:

- `godot/assets/fonts/` に候補3書体を同梱（いずれも SIL OFL 1.1）
- `ui/typography.gd` で書体と文字サイズを一元管理
- **カウンタと価格は等幅数字（tnum）**。毎フレーム変わる数値で桁が踊らないようにするため

## 13.2 ビルドに必要なもの

| | |
|---|---|
| macOS | Xcode が動くバージョン |
| Xcode | App Store から。初回起動でコマンドラインツールも入れる |
| Godot 4.3 | CI と同じ **4.3-stable**（他のバージョンだと挙動が変わりうる） |
| iOS 書き出しテンプレート | エディタ → エディタ → 書き出しテンプレートを管理 → ダウンロード |
| Apple ID | 無料でよい。無料だと**7日で失効**し、再インストールが必要 |

## 13.3 手順

```bash
git clone <このリポジトリ>
cd Incremental_game
python3 tools/sync_data.py        # godot/data/ を同期
```

1. **Godot でプロジェクトを開く** — `godot/` を開く（リポジトリ直下ではない）
2. **署名の設定** — プロジェクト → 書き出し → iOS プリセット
   - `Bundle Identifier` を自分のものに変える（例 `com.yourname.prisondebt`）
     **`com.example.` のままでは署名が通らない**
   - `App Store Team ID` に Apple Developer の Team ID を入れる
3. **Xcode プロジェクトとして書き出す** — 「プロジェクトを書き出し」を選ぶ
   （`.ipa` の直接書き出しは配布用。実機で試すだけなら Xcode 経由が速い）
4. **Xcode で開いて実機へ** — 生成された `.xcodeproj` を開く
   - Signing & Capabilities → Team に自分の Apple ID を選ぶ
   - デバイスを選んで ▶︎ で実行
5. **初回のみ** — iPhone 側で 設定 → 一般 → VPN とデバイス管理 →
   開発者アプリを信頼する

## 13.4 うまくいかないときに最初に見るところ

| 症状 | 原因 |
|---|---|
| 文字が全部 □ | フォントが同梱されていない（13.1）。`assets/fonts/` を確認 |
| 縦向きで起動する | 書き出し設定の `landscape_launch_screens` が false になっている |
| 署名エラー | Bundle Identifier が `com.example.` のまま／Team 未設定 |
| 7日で起動しなくなる | 無料 Apple ID の仕様。再インストールで戻る |
| 書き出しテンプレートが無いと言われる | 13.2 のテンプレートを入れていない |

## 13.5 フォント選定

`ui/main.gd` の `PREVIEW` を `true` にしてビルドすると、
起動時に比較画面（`ui/debug/font_preview.tscn`）が出る。
ボタンで書体を切り替えながら実機で見比べる。

| 候補 | 収録字数 | サイズ | 印象 |
|---|---|---|---|
| **Noto Sans JP** | 16,732 | 5.1MB | 癖がなく、字数が最も多い。迷ったらこれ |
| Zen Kaku Gothic New | 7,737 | 2.2MB | 角が立ち、やや硬い。監獄の雰囲気には合う |
| M PLUS 1p | 8,331 | 1.6MB | 丸みがあり軽い。軽快だが重厚さは出ない |

**見るべき点**

1. **カウンタの数字が踊らないか。** 所持額は毎フレーム変わる。
   等幅数字が効いていれば桁の位置が動かない
2. **右パネルの小さい文字（14px）で漢字が潰れないか。**
   「賄賂」「前提未達」あたりが判別できるか
3. 書体が舞台に合うか

**決めたあとにやること**

1. `ui/typography.gd` の `DEFAULT` を選んだ書体に変える
2. **使わない書体のファイルを削除する**（NFR-23 のダウンロードサイズ）
3. `ui/main.gd` の `PREVIEW` を `false` に戻す

## 13.6 実機で確かめること（フォント以外）

見た目の良し悪しは人間にしか判定できない。CI の ui-smoke は
「画面が組み上がるか」しか見ていない。

- [ ] 左レールと右パネルがノッチに食われていないか（セーフエリア）
- [ ] 下辺の「削る」ボタンに**両方の親指が自然に届くか**（NFR-02）
- [ ] 連打したときコンボが期待通り伸びるか。取りこぼしがないか
- [ ] 消灯時間のオーバーレイが読めるか、暗すぎないか
- [ ] 文字サイズ（`typography.gd` の SIZE_*）が小さすぎないか
- [ ] 30分遊んでバッテリーの減りが 10% を超えないか（NFR-22）
- [ ] 60fps を維持できているか（NFR-21）
