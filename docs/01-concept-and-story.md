# 01. コンセプトとストーリー

## 1.1 企画概要

| 項目 | 内容 |
|---|---|
| タイトル（仮） | PRISON DEBT / 監獄の借金 |
| ジャンル | インクリメンタル（放置・クリッカー）＋ミニゲーム集 |
| プラットフォーム | iOS / Android（**横持ち・両手持ち固定**） |
| プレイ時間 | 1周目クリア 3〜5時間 / 周回 25〜90分 / 1セッション 5〜15分 |
| 課金モデル | 基本無料 ＋ リワード広告 ＋ IAP（10章）。**ハードモードでは全て無効**（09章） |
| ターゲット | Fortune Mill / Cookie Clicker / Universal Paperclips を好む層。通勤・就寝前の隙間時間プレイヤー |
| コアの快感 | 「単位が変わる瞬間」＝ 1本 → 100本 → 1万本 → 100万本 と桁が上がるカタルシス |

## 1.2 コンセプト

**「借金は、稼いでも減らない。減るのは自由の方だ。」**

プレイヤーは一切の戦闘をしない。ひたすら牢屋の中の小さな経済圏で稼ぐ。
稼ぐ手段（ミニゲーム）と通貨はステージごとに完全に別物で、
前のステージで覚えた「効率化の思考」だけが持ち越される。

3つの柱:

1. **稼ぐ** — ステージ固有のミニゲームを手で触って通貨を得る
2. **強くする** — 稼いだ通貨でスキルツリーを開放し、単価・倍率・自動化を伸ばす
3. **買う** — 100万 を看守に渡し、次の牢屋へ移る

そして、それを **何度も繰り返す**（周回・08章）。
別軸として、すべての積み上げを無効にし、制限時間を課した
**ハードモード「死線」**（09章）がある。

## 1.3 ストーリー

### プロローグ

主人公は保証人となった友人の失踪により、返済不能な額の借金を背負う。
法廷は「労働による返済」を命じ、主人公は **収容施設セントレア** に送られる。

しかしこの施設は建前だけの更生施設で、内部は完全な闇経済で回っている。
看守は囚人から賄賂を受け取り、囚人を「次の棟」へ送る。
棟が変わるたびに通貨も稼ぎ方も変わり、囚人はまた一から稼ぎ直す。

> 「出してやるよ。相場は 100万。……ああ、ここの100万な。よそのは使えねえ」

### 進行

- 1つの棟（ステージ）で **100万** を稼ぐ
- 看守に渡すと解放される
- **解放された先は、別の看守が待つ別の牢屋**
- これを 5 回繰り返すと、最後の門が開く

### 5人の看守

| # | 棟 | 看守 | 性格 | 賄賂を受け取るときの台詞 |
|---|---|---|---|---|
| 1 | 独房棟 | ガルド（老獄吏） | 無気力。金額にしか興味がない | 「……数えるのも面倒だ。持っていけ」 |
| 2 | 労役棟 | メリナ（作業監督） | 効率主義。無駄を嫌う | 「時間通り。それだけは褒めてやる」 |
| 3 | 食堂棟 | ボッソ（賭場の胴元） | 陽気で残酷。イカサマを笑う | 「運がよかったな。運だけはな」 |
| 4 | 医務棟 | クーヤ（調剤師） | 静かで読めない。観察者 | 「あなた、ここに馴染みすぎです」 |
| 5 | 時計塔 | 所長ヴァレン | 全てを知っている。塔の巡回表を握る | 「時計を合わせたな。……いい腕だ」 |

各看守は賄賂の受け渡し演出のほか、ステージ中に **抜き打ち検査イベント**（一時的なデバフ／
ボーナスの選択）として登場し、ステージごとの個性を演出する。

### エンディング（二作目への引き）

5人目・所長ヴァレンに 100万 を渡すと、時計塔の門が開く。
解錠に必要なのは鍵ではなくタイミング ―― 5人の衛兵が同時に持ち場を離れる
GOLDEN WINDOW に合わせて、主人公は門をくぐる。
外に出た主人公が見るのは——

- 施設を囲む **さらに巨大な外壁**
- 壁の内側に広がる「街」。そこでは市民全員が首に端末をつけ、働き、返済している
- 主人公の端末に表示される残高: **借金残額 ―― 減っていない**

ヴァレンの最後の一言:

> 「ここも施設内だ。君が出たのは第一区画。……区画は、あと 5 つある」

`TO BE CONTINUED —— PRISON DEBT II: THE CITY`

エンディング後も **5つの棟はすべてプレイ可能なまま残る**。
後半コンテンツは3つある。

1. **継承ツリー**の最深部（密輸ルート5本）を埋めていく長期プレイ
2. **記録抹消（周回）** ―― 全てを失う代わりに脱獄章を得て、**永久スキル表**を埋める（08章）
3. **ハードモード「死線」** ―― 積み上げを全て無効にし、**制限時間の中で5棟を抜ける**（09章）

## 1.4 元ネタとの差分（なぜスマホ版として成立するか）

| 観点 | Fortune Mill | 本作 |
|---|---|---|
| 目標 | $1,000,000 を稼いで脱出 | 100万 × 5ステージ、通貨は毎回別。**賄賂はスキルツリーの最終ノードそのもの** |
| 部屋 | 同時にアクセス可能、相互にシナジー | 逐次解放だが、クリア後はハブ【廊下】から全棟を自由に往復できる。棟の相互作用は「継承ツリー」と「密輸ルート」で実現 |
| 操作 | マウスでダーツを投げる等 | 全ミニゲームを **両親指・横画面** に再設計。中央は表示、左右下端が操作 |
| 放置 | 自動化は購入で解放 | 同左＋ **オフライン進行**（スマホ前提の必須機能） |
| 批判点 | 「何百回も手動で遊ぶ必要がある」「効果音が過剰」 | 自動化の到達を早め、手動は常に「自動より速い」上位互換に留める。音は全レイヤー個別ON/OFF |
