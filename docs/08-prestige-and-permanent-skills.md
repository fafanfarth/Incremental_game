# 08. 周回（記録抹消）と永久スキル表

## 8.1 なぜリセットするのか

07章までの設計では、エンディング後の遊びは「継承ツリーを埋める」だけだった。
これは目標が一直線で、しかも数字が大きくなるほど1ノードあたりの体感が薄くなる。

そこで **周回（プレステージ）** を入れ、次の3層構造にする。

```
  第1層  1ステージの中の成長      ── 本編ツリー T1〜T6 と【賄賂】T7
  第2層  1周の中のステージ間成長  ── 継承ツリー L1〜L4 と密輸ルート
  第3層  周をまたぐ成長           ── 永久スキル表（本章）   ← 新規
```

第3層だけがリセットされない。これにより
**「1周を速く回して章を稼ぎ、永久スキルで次の周をもっと速くする」** という
インクリメンタルの王道ループが後半コンテンツとして成立する。

## 8.2 記録抹消（プレステージ）

### ストーリー上の扱い

エンディングで主人公は門を出るが、そこも施設の内側（第一区画）だった。
やがて捕まり、**また第一の牢屋に戻される**。
所持品も人脈も巡回表の書き換えも、すべて没収される ―― が、
**やり方は身体が覚えている**。

> ガルド「……またお前か。前も居たな、その顔」

### 実行条件

| 項目 | 内容 |
|---|---|
| 解放 | ステージ5の【賄賂】購入（＝エンディング到達）後、いつでも |
| 場所 | 廊下画面の「記録抹消」ボタン。実行前に獲得章の見込みを必ず表示する |
| 確認 | 2段階確認。失うものを一覧で提示する |
| 回数 | 無制限 |

### リセットされるもの / 残るもの

| リセットされる | 残る |
|---|---|
| 全5棟の通貨残高 | **永久スキル表と脱獄章** |
| 全5棟の本編ツリー（T1〜T7） | 実績・図鑑・カルテ |
| 全5棟の継承ツリー（L1〜L4）と密輸ルート | タイムアタックの記録（09章） |
| 反復購入アイテム（子分・機械Lv・基礎搬出量） | 設定・購入済みIAP（10章） |
| 棟の解放状態（棟1からやり直し） | 自己ベスト記録（最深層・最高ランク等） |

> **R-03 の改訂**: 「スキルツリーは永続」は **1周の中での話** に限定される。
> 周回でのみリセットされる。02章の R-03 はこの章を参照すること。

### 獲得章の式

```
獲得する脱獄章 = Σ_棟 floor( 3 × √( その棟の生涯獲得額 ÷ 1,000,000 ) ) × (1 + 前科ボーナス)
```

| プレイの深さ | 各棟の生涯獲得額 | 獲得章 |
|---|---|---|
| 最短クリアのみ | 約 175万 | **15章** |
| 継承 L1 まで | 約 500万 | **30章** |
| 継承 L2 まで | 約 2,500万 | **75章** |
| 継承 L4 まで（密輸5本） | 約 6.3億 | **375章** |

平方根を使うのは、**「もう少し深く掘ってから抹消する」判断に常に意味を持たせる**ため。
線形だと「早く抹消するのが常に最適」または「限界まで掘るのが常に最適」の
どちらかに倒れ、判断が消える。

### 周回の想定

| 周 | 想定所要 | やっていること |
|---|---|---|
| 1周目 | 3〜5時間 | 初見。全ステージを理解する |
| 2周目 | 1.5時間 | A系統の永久スキルで立ち上がりが速い |
| 3〜5周目 | 40〜60分 | 恩赦で好きな棟から始める。章を稼ぐ |
| 6周目以降 | 25〜40分 | 永久スキル表の埋め作業。タイムアタックへ |

## 8.3 永久スキル表

ツリーではなく **表（グリッド）** 形式にする。

- ツリーは「解放順の物語」を作るのに向くが、本編ツリー（04章）でもう5本やっている
- 永久スキルは **周回のたびに見返して、少しずつ埋めていく台帳** として機能させたい
- 全項目が最初から見えており、**Lv を上げていく** 形式が適している

### 表の形式

```
獄中手帳                                       所持 脱獄章 ▣ 128
┌──────────┬──────────────────────┬────────┬──────────┬────────┐
│ 分類      │ 項目                  │  Lv    │ 効果      │ 次Lv   │
├──────────┼──────────────────────┼────────┼──────────┼────────┤
│ A 記憶    │ 既視感                │ ▣▣▣□□ │ 開始+125k │  ▣12   │
│           │ 手順の記憶            │ ▣▣□□□ │ T1-T2 -40%│  ▣12   │
│ B 手癖    │ 硬い指                │ ▣▣▣▣▣▣□□□□ │ 手動+60% │ ▣14 │
│  …       │                       │        │           │        │
└──────────┴──────────────────────┴────────┴──────────┴────────┘
```

- 5分類 × 6項目 = **30項目**
- 各項目は Lv1〜最大Lv。`Lv n のコスト = base × n`
- **リセット（振り直し）は 1周につき1回まで無料**（項目 E2 で回数追加）

## 8.4 設計上の注意

1. **永久スキルは本編の数値を壊してよい**（周回前提なので当然速くなる）。
   ただし **ステージの対抗ギミック（03章 3.6）を無効化してはならない**。
   コンボは切れ、疑念値は溜まり、盤面は埋まり、周期範囲は重ならない。
   速くはなるが、**遊び方は変わらない**。
2. **タイムアタックでは永久スキルを全て無効化する**（09章）。
   ここを守らないとランキングが「何周したか」の順位表になり、意味を失う。
3. **リセット確認画面で「失うもの」を必ず全部見せる**。
   インクリメンタルで最も嫌われるのは、意図しないリセットである。
4. **1周目のプレイヤーに永久スキル表を見せない**。
   エンディングまで存在を隠す。第3層は「その先にまだあった」という発見であるべき。
