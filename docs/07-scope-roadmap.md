# 07. 開発スコープとロードマップ

## 7.1 スコープの切り方

本作の最大のリスクは **「ステージが5つある ＝ ミニゲームを5本作る」** 点にある。
実質的に小さなゲームを5本作る企画であり、全てを同時に作り始めると必ず破綻する。

そこで **縦に1本通してから横に広げる**。

## 7.2 フェーズ

### Phase 0 — 数値プロトタイプ（1〜2週）
UI をほぼ作らず、ボタンとテキストだけで **ステージ1の経済** を実装する。

- 目的: 5章の成長曲線（P0〜P5）が実際に 25分で回るかの検証
- 成果物: Web で動く数値シミュレータ。スキル24ノードとコスト階梯が外部JSON
- **合格条件**: 手動プレイで 25分±5分、放置のみで 60分±15分に着地する

### Phase 1 — 垂直スライス（4〜6週）
**ステージ1のみを製品品質で完成させる。**

- 壁削りミニゲーム、子分、消灯時間、スキルツリーUI、抜き打ち検査、看守ガルドの賄賂演出
- セーブ / オフライン進行 / 設定（音の個別ON/OFF）
- **合格条件**: 社外テスター10名が「独房棟をクリアして、次が遊びたい」と言う

### Phase 2 — 横展開（各 3〜4週 × 3）
ステージ2〜4 を1本ずつ追加する。Phase 1 で確立した
**共通フレーム（通貨カウンタ / ツリー / 検査 / 賄賂）は再利用** し、
新規実装はミニゲーム本体と固有ギミックのみに限定する。

- 各ステージ完成ごとに Phase 0 の数値検証を再実施
- この時点で「共通フレームに載らないミニゲーム案」は **落とす**

### Phase 3 — ステージ5とエンディング（4週）
中央塔は 1〜4 の縮小版を組み合わせるため、**既存実装の再利用率が最も高い**。
逆に言えば、Phase 2 までで各ミニゲームを部品として切り出しておくことが前提になる。

- 共鳴システム、所長ヴァレンの対話、門の解錠カットシーン、エンディング

### Phase 4 — 仕上げ（4週）
- NG+ / メダルツリー / Lethal（タイムアタック）
- 実績 50件、図鑑、ローカライズ（英語）
- パフォーマンス最適化（NFR-21 / 22）、ストア素材

**合計: 約 5〜6ヶ月**（少人数チーム想定）

## 7.3 MVP（最小で世に出せる範囲）

| 含む | 含まない |
|---|---|
| ステージ1〜2 | ステージ3〜5 |
| スキルツリー 2本 | NG+ / Lethal |
| オフライン進行・セーブ | クラウドセーブ |
| 日本語 | 英語 |
| 賄賂演出 2種 | エンディング |

MVP のエンディングは **「第3の牢屋の扉が開く」ところで To be continued** とし、
ストア上は早期アクセス／無料版として配信、以降のステージをアップデートで追加する。

## 7.4 リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| ミニゲームが5本＝実質5本の開発 | 工期の爆発 | Phase 2 で共通フレームに載らない案を落とす。ステージ5は再利用で作る |
| ステージごとに一から稼ぎ直す＝作業感 | 3ステージ目で離脱 | 人脈ボーナス（R-04）で「積み上がり」を可視化。新ステージの立ち上がりは意図的に速くする（NG+「記憶の継承」も同趣旨） |
| ステージ3のプラス期待値ギャンブル | 放置で無限増殖 | 自動投擲に試行時間とベット上限の制約（04章の注記） |
| 通貨が毎回リセットされる不快感 | 「稼いだ意味がない」 | 余剰没収をペナルティ表示しない。賄賂＝物語の前進として演出で納得させる |
| 手動連打の疲労 | 短期離脱 | 自動化を 25〜35% 地点に必ず配置（FR-11）。長押しオートタップを早期に開放 |
| 参考タイトルと同様の音の不評 | レビュー評価の低下 | NFR-07 / 08 を Phase 1 の合格条件に含める |
| 数値のオーバーフロー | NG+ で破綻 | BigNumber を Phase 0 から導入（NFR-26） |

## 7.5 次にやること（着手順）

1. 本設計書のレビューと、ステージ2〜5 のミニゲーム案の確定
2. Phase 0 の数値シミュレータ実装（ステージ1のみ、UIなし）
3. 5章の成長曲線の実測と、コスト階梯（T1〜T6）の再調整
4. スキル定義を外部JSON化し、バランス調整をデータ編集だけで回せる状態にする
5. Phase 1 着手（エンジン選定を先に確定すること：Unity 6 / Godot 4 / Web）
