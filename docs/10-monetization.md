# 10. 課金・広告設計

## 10.1 方針の転換

06章の初版では「買い切り（推奨）」としていた。本章でこれを **基本無料（F2P）＋ 広告 ＋ IAP** に変更する。

その上で、インクリメンタルの課金設計で最も壊れやすい点を、構造で解決する。

> **問題**: 放置ゲームで課金すると、課金した人としていない人で数字が何桁も変わる。
> 難易度のあるモードを足すと、そこは即座に「課金すれば勝てるモード」になる。
>
> **解決**: 課金と広告の効果を **ストーリーモードに閉じ込め、ハードモードでは全て無効化する**（09章）。
> 数字を伸ばす場所では好きなだけ時間を買える。腕を試す場所では誰もが同条件。

この分離があるため、以下の設計では **時短系の課金を遠慮なく置ける**。

## 10.2 変更後の原則

| ID | 原則 |
|---|---|
| M-01 | 課金・広告が提供するのは **時間短縮と利便性のみ**。無課金で到達できない数値・コンテンツを作らない |
| M-02 | **強制的な全画面広告を出さない**。広告は全てプレイヤーが自分で選んで見るリワード型 |
| M-03 | **ガチャ・ルートボックスを実装しない**。何が手に入るかは購入前に必ず確定している |
| M-04 | **ハードモードでは課金・広告の効果を全て無効化する**（09章 FR-51） |
| M-05 | 広告視聴はいずれも **1日の上限を設ける**。見続ければ無限に進む状態を作らない |
| M-06 | 購入は全て **買い切りまたは明示的なサブスク**。自動更新は設定から常に確認できる |
| M-07 | 13歳未満と判定されるアカウントには **パーソナライズ広告を配信しない**（COPPA / GDPR-K 対応） |

> M-03 について: ステージ3（食堂棟）はゲーム内容としては賭博だが、
> **賭けるのは常にゲーム内通貨のみ**であり、実通貨との接点を一切持たせない。
> IAP で食堂棟のチップを直接売ることもしない。

## 10.3 広告（リワード型のみ）

| 枠 | 報酬 | 1日の上限 | 導線 |
|---|---|---|---|
| **差し入れ** | 90秒間、全獲得 ×3 | 4回 | 廊下・棟画面の常設ボタン |
| **留守中の稼ぎ ×2** | オフライン獲得を2倍にして受け取る | 3回 | 復帰ダイアログ内 |
| **現地調達** | 現在CPSの30分ぶんを即時獲得 | 5回（CD 15分） | 棟画面。所持額が伸び悩んだときに提案 |
| **看守の見逃し** | 抜き打ち検査を1回スキップ | 3回 | 検査ダイアログの第3の選択肢 |
| **恩赦の前借り** | 記録抹消時の獲得章 +20% | 周回ごと1回 | 記録抹消の確認画面 |
| **一括購入の拡張** | 24時間、一括購入 ×100 を解放 | 1回 | ツリー画面（P-C5 未取得者向け） |

### 設計上の注意

- **広告の導線を「詰まったとき」に出す**。所持額の伸びが一定時間止まったら「現地調達」を提案する
- **復帰ダイアログの ×2 が最も視聴率が高い**（放置ゲームの定番）。ここだけは必ず実装する
- **「看守の見逃し」はゲーム性への介入が最も小さい**。検査は元々期待値が同等なので、
  広告でスキップしても数値バランスが崩れない
- 広告のロード失敗時は **報酬を与えて成功扱いにする**（プレイヤーのせいではないため）

## 10.4 IAP（買い切り＋1種のサブスク）

価格は日本のストア価格帯での例示。

### 恒久アンロック

| 商品 | 価格 | 内容 |
|---|---|---|
| **監獄手帳（広告除去）** | ¥730 | 広告バナーを全撤去。加えて「差し入れ」相当の **常時 ×1.5** が付く |
| **段取りパック** | ¥730 | オフライン上限 +8時間（恒久）、一括購入 ×100 / ×1000 を即解放 |
| **初回パック**（初回起動から7日間のみ） | ¥370 | 脱獄章 30 + 広告除去 7日間 + 開始時所持額ブースト |

> **「監獄手帳」が主力商品**。広告除去と常時ブーストを束ねることで、
> 「広告を消す」という守りの購入に、進行が速くなるという攻めの価値を足す。

### 脱獄章パック（永久スキル用）

| 商品 | 価格 | 脱獄章 | 1章あたり |
|---|---|---|---|
| 小 | ¥370 | 50 | ¥7.4 |
| 中 | ¥1,200 | 200 | ¥6.0 |
| 大 | ¥3,600 | 700 | ¥5.1 |

- 永久スキル表の総額は **4,474章**（08章）。全て課金で埋めると約 ¥23,000
- 周回で稼げば無課金でも 50周で到達する。**課金は「50周を短縮する」対価**
- **販売するのは章のみ。永久スキルそのものを個別に売らない**（M-01 の担保）

### スキン（ゲーム性に影響しない）

| 商品 | 価格 | 内容 |
|---|---|---|
| 牢屋スキン | ¥370〜¥610 | 各棟の背景・BGMのバリエーション |
| 看守スキン | ¥370 | 5人の看守の見た目違い |
| 数字スキン | ¥250 | カウンタの書体・色（漢数字、算用数字、タリー） |
| 全スキンパック | ¥2,400 | 以降追加されるスキンも含む |

### サブスク

| 商品 | 価格 | 内容 |
|---|---|---|
| **獄中日誌** | ¥610 / 月 | 全ランの詳細記録と棟別ラップの分析、周回ごとの年表、スキン月替わり配布、専用称号 |

- **獄中日誌はゲームの有利さを一切売らない**（M-04 により、ハードモードで有利になる商品は作れない）
- 売っているのは **記録と分析と見せびらかし** のみ
- 未加入でもハードモードは全難易度プレイでき、記録も残る

> **サブスクは優先度が最も低い。** 売るものが薄いなら、無理に入れず
> 買い切り商品だけで始めてよい（07章 Phase 5）。

## 10.5 何を売らないか

明確に「売らない」と決めておく。ここが曖昧だと、運営中に必ず崩れる。

| 売らないもの | 理由 |
|---|---|
| ステージ通貨（タバコ・チップ・錠剤 等） | 経済が即座に壊れる。特に食堂棟は実質的な賭博課金になる |
| 本編ツリー・継承ツリーのノード | M-01 に反する。1周の攻略そのものを売ることになる |
| ステージのスキップ | 買った人がゲームを遊ばなくなる |
| ハードモードで有利になる一切のもの | M-04 |
| ガチャ・確率型商品 | M-03 |
| 進行を止めるスタミナと、その回復 | インクリメンタルの前提（R-10 前進のみ）と矛盾する |

## 10.6 要件

| ID | 要件 | 優先度 |
|---|---|---|
| FR-60 | 広告は全てリワード型とし、プレイヤーの操作を起点にのみ再生される | 必須 |
| FR-61 | 各広告枠に1日の視聴上限を設け、残り回数を常に表示する | 必須 |
| FR-62 | 広告のロードに失敗した場合も報酬を付与する | 必須 |
| FR-63 | IAP は買い切りとサブスクを提供し、購入内容を購入前に全て明示する | 必須 |
| FR-64 | 購入の復元（Restore）に対応する | 必須 |
| FR-65 | ハードモードでは全ての課金・広告効果を無効化する | 必須 |
| FR-66 | サブスクは解約導線をアプリ内の設定から1タップで開ける | 必須 |
| FR-67 | 年齢帯に応じてパーソナライズ広告の可否を切り替える | 必須 |
| FR-68 | 所持額の伸びが一定時間停滞したとき、該当する広告枠を控えめに提案する | 推奨 |
| FR-69 | レシート検証はサーバ側で行う（クライアント単独で購入を確定しない） | 必須 |

## 10.7 収益の目安

インクリメンタル／放置ゲームの一般的な水準を置いた試算。実測で更新する。

| 指標 | 目標値 |
|---|---|
| IAP 課金率（課金ユーザー / DAU） | 2〜4% |
| 広告視聴率（1日1回以上見る / DAU） | 45〜60% |
| 1人あたり1日の広告視聴回数（視聴者のみ） | 4〜6回 |
| ARPDAU（広告 + IAP 合計） | ¥12〜¥25 |
| 広告 : IAP の収益比 | おおむね 4 : 6 |
| 「監獄手帳」購入率 | 課金ユーザーの 60% 以上（主力商品として機能しているか） |
| ハードモード挑戦者の課金率 | 全体平均を下回らないこと（無効化が課金意欲を殺していないか） |

### 監視すべき異常

| 兆候 | 疑い |
|---|---|
| 広告視聴率が 70% を超える | 広告なしでは進めない設計になっている（M-01 違反） |
| 「現地調達」だけ突出して視聴される | ゲーム側の成長曲線に穴がある（05章の再調整） |
| 脱獄章パックの売上比率が 50% を超える | 周回のペースが遅すぎる。08章の獲得章式を見直す |
| 獄中日誌の解約率が月 40% を超える | 記録と分析の中身が薄い。サブスク廃止を検討する |

## 10.8 06章との差分

本章により、06章の以下の記述を置き換える。

| 旧（06章 初版） | 新 |
|---|---|
| 課金モデル: 買い切り（推奨） | **基本無料 ＋ リワード広告 ＋ IAP** |
| NFR-10 課金・広告は時間短縮のみ | → M-01（維持。ただし脱獄章の販売を明示的に許容） |
| NFR-11 強制広告を出さない | → M-02（維持） |
| NFR-12 ガチャを実装しない | → M-03（維持） |
| （なし） | → M-04 **ハードモードでの全無効化**（新規・最重要） |
