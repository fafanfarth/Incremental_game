# 02. ゲームルール

## 2.1 コアループ

```
        ┌──────────────────────────────────────────────┐
        │                                              │
        ▼                                              │
  ① ミニゲームを遊ぶ（タップ／スワイプ／放置）          │
        │                                              │
        ▼                                              │
  ② ステージ通貨を獲得                                  │
        │                                              │
        ├──→ ③ スキルツリーに投資（単価↑ 倍率↑ 自動化）──┘
        │
        ▼
  ④ ツリー最深部の【賄賂】ノード（1,000,000）を購入
        │
        ▼
  ⑤ 看守が扉を開ける ＝ 次のステージが解放される
        │
        ├──→ ⑥ 賄賂ノードの先に【継承ツリー】が出現
        │        （この棟の通貨で買い、次以降の棟に効く）
        │
        ▼
  ⑦ 次の牢屋へ。ただし前の牢屋はいつでも戻れる
```

**賄賂はイベントではなくスキルノードである。** これが本作の中心的な構造。
クリア条件・継続プレイ・ステージ間の引き継ぎが、すべて「ツリーを買い進める」
という1つの操作に統合される。

## 2.2 全ステージ共通ルール

### R-01 目標＝賄賂ノードの購入
各ステージのクリア条件は、スキルツリー最深部（T7）の **【賄賂】ノードを
1,000,000 で購入すること**。他のノードと同じく通貨を消費して買う。

- 所持額が 1,000,000 に届くと、ツリー画面の賄賂ノードが点灯する
- 購入すると看守のカットシーンが再生され、次のステージが解放される
- **購入で消費されるのは 1,000,000 ちょうど**。超過分は手元に残る

### R-02 通貨の非互換
通貨はステージ間で持ち越せず、両替もできない。
ただし **没収はされない**。棟を移っても、その棟の通貨は残高として保持され続ける。
（唯一の例外が R-12 の密輸ルート）

### R-03 スキルツリーは永続
ツリーはリセットされない。買ったノードは最後まで有効で、
**クリア済みの棟に戻れば、育て切ったツリーがそのまま動いている**。

### R-04 継承ツリー（賄賂ノードの先）
賄賂ノードを購入すると、その先に **継承ツリー（L1〜L4）** が開く。

- 購入には **その棟の通貨** を使う（＝クリア後もその棟で稼ぐ理由になる）
- 効果は **次のステージ以降** に及ぶ。現在の棟には何の効果もない
- コストは本編ツリーより 1〜2桁高い（L1: 300万 〜 L4: 5億）
- L4 は全ステージ共通で **密輸ルート**（R-12）

これにより「前の棟で稼ぐ → 今の棟が強くなる」という往復が生まれる。
引き継ぎ内容は固定のボーナスではなく、**プレイヤーが何を引き継ぐかを選ぶ**。

### R-05 棟の往来（クリア後の継続プレイ）
クリアした棟には、下タブの **【廊下】** からいつでも戻れる。

> 物語上の理由: 賄賂を払った囚人は看守の「使い走り」として棟の間を行き来する
> 権利を得る。自由ではないが、動ける。

- 戻った棟では **抜き打ち検査（R-09）は発生しない**（顔パス）
- 戻った棟のミニゲームは制限なく全て遊べる
- 賄賂ノードは1回限り。再購入はできない

### R-06 並行自動収入
クリア済みの棟の自動収入は、**別の棟にいる間も回り続ける**。

- 表示していない棟の演算は簡略化し、CPS × 経過秒でのみ加算する（NFR-21）
- 各棟の残高は廊下画面で一覧できる
- これにより、ステージ3を遊びながらステージ1の残高が継承ノード分まで貯まる

### R-07 自動化
各ステージに最低 1 つの自動化スキル（T3帯）が存在し、
**プレイ時間の概ね 25〜35% 地点** で到達できる。
自動化解放後はアプリを閉じても R-08 のオフライン進行が働く。

### R-08 オフライン進行
- 自動化を1つ以上所持する棟が対象。**解放済みの全棟が同時に蓄積する**
- 各棟につき **自動収入の 60%**
- 上限 **8時間**（継承ノードで最大 +4h。広告で一時延長可）
- 復帰時に棟ごとの内訳をダイアログで提示し、受け取り操作で加算

### R-09 抜き打ち検査（未クリアの棟でのみ発生）
未クリアの棟では、ステージ通算プレイ時間の一定間隔（初回 5分、以降ランダム
4〜8分）で看守が巡回に来る。プレイヤーは 2 択を迫られる:

| 選択 | 結果 |
|---|---|
| **隠す** | 60% で成功（何も起きない）／40% で失敗（所持額の 10% を失う） |
| **袖の下を渡す** | 所持額の 5% を確実に失う代わりに、90秒間 **獲得量 ×2** |

期待値はほぼ同等に設定し、「安定か、加速か」の好みの表明に留める。
所持額が 1,000,000 に達している間は検査は発生しない（クリア直前の理不尽を避ける）。

### R-10 失敗しないゲームであること
**ゲームオーバーは存在しない**。所持額が 0 になっても手動プレイで必ず再開できる。
インクリメンタルとして「前進のみ」を保証する。

### R-11 クリア後も数値は伸び続ける
上限（カンスト）を設けない。反復購入型アイテム（子分・機械Lv 等）は
無限に買い続けられ、CPS は継承ツリーの最深部（5億）に届くまで成長する。

### R-12 密輸ルート（L4ノード）
各棟の継承ツリー最深部を買うと開通する、**通貨非互換の唯一の例外**。

```
流入額 = 開通済みの棟の自動収入(CPS) × 5% × 現在の棟のレート補正
```
- 流入先は **プレイヤーが現在いる棟** の通貨（自動で換算される）
- 5棟すべて開通すると、どの棟にいても他4棟が稼ぎを送り続ける
- これが Fortune Mill の「各部屋が互いに影響し合う」に相当する最終形

## 2.3 進行フロー（画面遷移）

```
[起動]
   └─ [タイトル / CONTINUE]
         └─ [廊下]（ハブ・下タブ）
              ├─→ [棟1 独房棟]   ─┬─→ [スキルツリー]（棟ごと）
              ├─→ [棟2 労役棟]   ─┤     ├ 本編 T1〜T6
              ├─→ [棟3 食堂棟]   ─┤     ├ 【賄賂】T7
              ├─→ [棟4 医務棟]   ─┤     └ 継承 L1〜L4（賄賂購入後に出現）
              └─→ [棟5 時計塔]   ─┘
              │
              ├──→ [図鑑・実績]
              └──→ [設定]

  【賄賂】購入 → [看守カットシーン] → [次の棟が解放] → [廊下]
  棟5の【賄賂】購入 → [エンディング] → [NG+ 解放] → [廊下]（全棟プレイ可能なまま）
```

**廊下** が本作のハブ画面。各棟のタイル上に「現在の残高 / CPS / 継承ツリーの進捗」
を表示し、どの棟に戻れば何が買えるかが一目で分かるようにする。

## 2.4 チュートリアル方針

- 各ステージの冒頭 30秒 を「操作の説明」に充て、テキストは 1画面 2行まで
- 新ステージでは **必ず手動操作から始まる**（自動化は未所持）ので、
  「触り方」を体で覚えさせてから経済を開く
- 2ステージ目以降は共通UI（ツリー・カウンタ・タブ）の説明を省略する
- **棟2クリア直後に「廊下に戻って棟1の継承ノードを買う」導線を必ず挟む**。
  ここで往復の楽しさを教えないと、継承ツリーが死に機能になる
