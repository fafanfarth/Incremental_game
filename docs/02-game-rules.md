# 02. ゲームルール

## 2.1 コアループ

```
        ┌──────────────────────────────────────────────┐
        │                                              │
        ▼                                              │
  ① ミニゲームを遊ぶ（タップ／スワイプ／放置）          │
        │                                              │
        ▼                                              │
  ② ステージ通貨を獲得                                  │
        │                                              │
        ├──→ ③ スキルツリーに投資（単価↑ 倍率↑ 自動化）──┘
        │
        ▼
  ④ 所持額 1,000,000 に到達
        │
        ▼
  ⑤ 看守に賄賂を渡す（所持額 100万 を全額消費）
        │
        ▼
  ⑥ 次の牢屋へ（通貨・ミニゲーム・スキルツリーが全て入れ替わる）
```

1ステージの想定サイクルは「手動で種銭を作る → 自動化を買う → 放置で伸ばす →
手動で加速して一気に突破」。**手動プレイは常に自動より高効率**（おおむね自動の 3〜5倍）に
設計し、「触ると速い／触らなくても進む」を両立させる。

## 2.2 全ステージ共通ルール

### R-01 目標額
各ステージのクリア条件は **そのステージの通貨を 1,000,000 所持していること**。
累計獲得額ではなく **所持額**。スキルに使った分は目標に含まれない。

### R-02 通貨の非互換
通貨はステージ間で持ち越せず、両替もできない。
ステージクリア時、余剰分（100万を超えた分）は **没収** される。
> 演出: 看守「端数は手数料だ」——プレイヤーに「100万ちょうどで渡す」動機を与えない
> ため、余剰は没収するがペナルティ表示はせず、静かに 0 に戻す。

### R-03 スキルツリーの非互換
スキルツリーもステージ固有。クリア後もツリーの内容は閲覧できる（図鑑）が、効果は失われる。
代わりに **人脈ボーナス**（R-04）が残る。

### R-04 人脈ボーナス（クリア済みステージの恒久効果）
クリアしたステージごとに、以降の全ステージへ適用される小さな永続効果が 1 つ付与される。
ステージが進むほど手数が増え、「積み上げている感」を担保する。

| クリアしたステージ | 人脈ボーナス | 効果 |
|---|---|---|
| 1 独房棟 | 「スプーンの記憶」 | 手動タップの獲得量 +15% |
| 2 労役棟 | 「作業票のコネ」 | オフライン進行の効率 +10%（上限時間も +2h） |
| 3 食堂棟 | 「胴元の目」 | すべてのランダム判定の期待値 +10% |
| 4 医務棟 | 「処方箋」 | ブースト系効果の持続時間 +25% |
| 5 中央塔 | （NG+ で解放） | 全ステージの通貨獲得 +50% |

### R-05 自動化
各ステージに最低 1 つの自動化スキル（オートプレイ）が存在し、
**ステージ通貨の 1〜3% 程度の価格帯**（＝プレイ時間の概ね 25〜35% 地点）で到達できる。
自動化解放後はアプリを閉じても R-06 のオフライン進行が働く。

### R-06 オフライン進行
- 自動化を1つ以上解放している場合のみ有効
- アプリ非起動中は **自動収入の 60%** が蓄積（人脈ボーナスで上昇）
- 上限 **8時間**（人脈ボーナスで最大 +2h。IAP/広告で一時延長可）
- 復帰時に「留守中の稼ぎ」をダイアログで提示し、受け取り操作で加算

### R-07 賄賂
- 所持額が 100万 に達すると、画面下部に **「看守を呼ぶ」ボタン** が常時出現
- 押すとカットシーン（看守ごとの固有演出、2〜4秒、スキップ可）
- 受け渡し後、次ステージのチュートリアルへ
- **100万到達後もステージに留まって遊べる**（実績・コレクション収集のため）。
  ただし余剰は R-02 により没収される旨を事前に明示する

### R-08 抜き打ち検査（ステージ内イベント）
ステージ通算プレイ時間の一定間隔（初回 5分、以降ランダム 4〜8分）で看守が巡回に来る。
プレイヤーは 2 択を迫られる:

| 選択 | 結果 |
|---|---|
| **隠す** | 60% で成功（何も起きない）／40% で失敗（所持額の 10% を没収） |
| **袖の下を渡す** | 所持額の 5% を確実に失う代わりに、90秒間 **獲得量 ×2** |

期待値はほぼ同等に設定し、「安定か、加速か」の好みの表明に留める。
所持額が 100万 に達している間は検査は発生しない（クリア直前の理不尽を避ける）。

### R-09 失敗しないゲームであること
**ゲームオーバーは存在しない**。所持額が 0 になっても手動プレイで必ず再開できる。
インクリメンタルとして「前進のみ」を保証する。

### R-10 プレイヤーの唯一の資源は「時間」と「注意」
課金・広告はいずれも時間短縮のみを提供し、到達不能な数値を売らない（06章 NFR-09）。

## 2.3 進行フロー（画面遷移）

```
[起動]
   └─ [タイトル / CONTINUE]
         └─ [ステージ画面] ────┬──→ [スキルツリー]（下タブ）
              │               ├──→ [図鑑・実績]（下タブ）
              │               └──→ [設定]（下タブ）
              │
              ├─(検査イベント)─→ [選択ダイアログ]
              │
              └─(100万到達)───→ [看守を呼ぶ] → [賄賂カットシーン]
                                               └─→ [次ステージ導入] → [ステージ画面]

  ステージ5クリア → [エンディング] → [NG+ 解放] → [タイトル]
```

## 2.4 チュートリアル方針

- 各ステージの冒頭 30秒 を「操作の説明」に充て、テキストは 1画面 2行まで
- 新ステージでは **必ず手動操作から始まる**（自動化は未所持）ので、
  「触り方」を体で覚えさせてから経済を開く
- 2ステージ目以降は共通UI（スキルツリー・カウンタ・タブ）の説明を省略する
