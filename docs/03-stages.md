# 03. ステージ設計

5つのステージは「インクリメンタルの遊び方の型」を1つずつ変えて配置する。
同じ100万でも、到達の仕方が毎回違うことが本作の背骨。

## 3.0 一覧

| # | 棟 | 通貨 | 遊びの型 | 数学的な正体 | 主操作 | 毎秒の意思決定 |
|---|---|---|---|---|---|---|
| 1 | 独房棟 | タバコ | クリッカー | **反復購入の逓増コスト** | タップ連打 | 連打を続けるか、買いに行くか |
| 2 | 労役棟 | 作業票 | 生産ライン | **ボトルネックと最適配置** | ドラッグ配置 | どこが詰まっているか |
| 3 | 食堂棟 | チップ | ギャンブル | **複利と分散** | ベット→投擲 | いくら賭けるか |
| 4 | 医務棟 | 錠剤 | マージパズル | **在庫回転率 vs 指数価値** | ドラッグ合成 | 売るか、育てるか |
| 5 | 中央塔 | 金塊 | 直列生産 | **多段パイプラインの均衡** | 全部 | どの階に投資するか |

**設計意図**: 5つとも「数字を増やす」ゲームだが、**増やし方の数学が全部違う**。
プレイヤーは棟を移るたびに、新しい最適化問題を解き直すことになる。

## 3.1 ステージ1：独房棟 ／ 通貨「タバコ（本）」

> **一言でいうと**: 石壁を素手で削る。削った分だけタバコになる。
> 囚人仲間を買収すると、自分が寝ていても誰かが削ってくれる。

### 画面構成（縦画面）

```
┌────────────────────────────┐
│  🚬 12,480本   [████░░░] 100万 │ ← 所持額と進捗バー（常時固定）
├────────────────────────────┤
│                            │
│         ▓▓▓▓▓▓▓▓▓          │
│        ▓▓  石壁  ▓▓         │ ← タップ対象。ひび割れが蓄積して見える
│         ▓▓▓▓▓▓▓▓▓          │   第 7 層 / 残り 2,140 ダメージ
│                            │
│      ✊ COMBO ×12  +120%    │ ← コンボ表示
├────────────────────────────┤
│ 新入り    ×24   15,200本 [買] │
│ 古株      ×8   142,000本 [買] │ ← 子分（反復購入・下半分＝親指圏）
│ 掃除夫    ×1  1,380,000本[買] │
├────────────────────────────┤
│  [棟] [ツリー] [図鑑] [設定]   │
└────────────────────────────┘
```

### コアミニゲーム「壁削り」

**壁は層構造になっている。** タップで現在の層にダメージを与え、削り切ると
次の層へ進み、層ボーナスが入る。これが「掘り進んでいる感」の実体。

```
層 n の必要ダメージ = 10 × 1.35^n
層 n の突破報酬     = 50 × 1.60^n
1タップのダメージ   = TapPower × (1 + コンボ倍率)
```

必要ダメージ（1.35^n）より報酬（1.60^n）の方が速く伸びるため、
**層を進めるほど1層あたりの旨味が増える**。プレイヤーは「もう1層だけ」と手を止めなくなる。

### コンボ（このステージ唯一の緊張）

- 0.5秒以内に次のタップで **コンボ +1**
- 10コンボごとに **+10%**（上限 +100%、スキル S1-B3 で +200%）
- **2秒 触らないと 0 に戻る**（S1-B2 で 4秒、S1-B6 でリセット無効）

ここから **このステージ唯一かつ明快なジレンマ** が生まれる:

> **連打し続けてコンボを維持するか、手を止めて子分を買いに行くか。**

子分の購入ボタンは画面下部にあり、押すとコンボが切れる。
序盤はこの数秒の損失が重い。プレイヤーは自然と
「コンボを稼ぐ → 一気に買う → また積み直す」というリズムを見つける。
スキル S1-B2（保持4秒）と一括購入ボタン（×10 / ×最大）がこの摩擦を段階的に溶かす。

### 子分（自動収入）

```
cost(n) = base × 1.15^n
```

| 種類 | base | 1人あたり CPS | 解放条件 |
|---|---|---|---|
| 新入り | 15 | 0.2 /秒 | 最初から |
| 古株 | 800 | 3.5 /秒 | 新入り 10人 |
| 掃除夫 | 45,000 | 60 /秒 | 古株 10人 |
| 看守補佐 | 2,600,000 | 1,100 /秒 | 掃除夫 10人（クリア後に主力になる） |

Cookie Clicker 系の標準 `1.15^n`。「あと1人が少しずつ高くなる」感触が
このステージのテンポそのもの。**上限は無し**（R-11）。

### 消灯時間（放置を教えるギミック）

3分ごとに30秒、画面が暗転し **手動タップが不可** になる。その間は自動収入 ×2。

- 手動が封じられることで、プレイヤーは初めて「自動収入が無いと止まる」と体感する
- ここで必ず子分を買いに行く。**自動化の必要性を、説明ではなく体験で教える設計**
- スキル S1-B5「眠らない男」で消灯中もタップ可能になる＝制約の解除が報酬になる

### 隠し物（1回限りの固定報酬）

累計で一定層に到達するたびに壁から出る。ライター（ブースト解放）、写真（図鑑）、
宝くじ券（ステージ3の予告）など。**次の棟の伏線を置く枠** としても使う。

### フェーズ体験

| フェーズ | プレイヤーは何をしているか |
|---|---|
| P0 0〜2分 | ひたすら壁をタップ。数字が 1桁→3桁になる |
| P1 2〜6分 | 新入りを買う。手を止めても数字が増えることに気づく |
| P2 6〜12分 | 消灯時間で殴られる。古株を揃える。S1-C3 でオートタップ解放 |
| P3 12〜20分 | 層が 15 を超え、1層突破で万単位が入る。倍率スキルを取る |
| P4 20〜28分 | 掃除夫が並び、放置だけで伸びる。コンボ上限解放で手動が化ける |
| P5 28〜35分 | 100万到達。ツリー最深部の【賄賂】が点灯する |

### クリア後の遊び方

- **看守補佐の無限購入**が主軸。CPS を継承ツリー（最大 5億）に向けて伸ばす
- 最深層（第50層〜）への到達記録が実績になる
- 廊下から戻るたび、放置分の層が自動で進んでいる

### この棟の継承先
→ **手動系と序盤加速**。ステージ2以降の立ち上がりを短縮する方向（04章 S1-L1〜L4）。

## 3.2 ステージ2：労役棟 ／ 通貨「作業票（枚）」

> **一言でいうと**: 3本のベルトコンベアに機械を並べる。
> 素材が上から流れ、正しい順に加工されると価値が12倍ずつ跳ね上がる。

### 画面構成

```
┌────────────────────────────┐
│  🎟 842,000枚  [██████░] 100万 │
├────────────────────────────┤
│  ▼素材   ▼素材   ▼素材        │
│ ┌─────┬─────┬─────┐         │
│ │プレス│プレス│ ―  │ ← スロット1  │
│ ├─────┼─────┼─────┤         │
│ │縫製 │縫製 │プレス│ ← スロット2  │
│ ├─────┼─────┼─────┤         │
│ │梱包 │ ⚠詰 │縫製 │ ← スロット3  │
│ ├─────┼─────┼─────┤         │
│ │ ―  │ ―  │梱包 │ ← スロット4  │
│ └─────┴─────┴─────┘         │
│      ▼換金   ▼換金   ▼換金     │
├────────────────────────────┤
│ [プレス][縫製][梱包]  [残業 ▶] │
├────────────────────────────┤
│  [棟] [ツリー] [図鑑] [設定]   │
└────────────────────────────┘
```

### コアミニゲーム「ベルトコンベア」

3レーン × 4スロットのグリッド。素材がレーン先頭から下へ流れ、
スロットに機械があれば加工される。最下段に到達したものが自動換金される。

**加工チェーン（価値は ×12 ずつ）**

| 段階 | 品目 | 価値 | 必要な機械 |
|---|---|---|---|
| 0 | 素材 | 1 | ― |
| 1 | 部品 | 12 | プレス |
| 2 | 中間品 | 144 | 縫製 |
| 3 | 完成品 | 1,728 | 梱包 |
| 4 | 精密品 | 20,736 | 研磨（S2-A5 で解放） |

**加工は順番通りでなければ通らない。** 素材にいきなり梱包を当てても何も起きない。
つまりレーンは `プレス → 縫製 → 梱包` の順に並んでいる必要がある。

### 配置のジレンマ（このステージの中核）

2種類のボーナスが **相反する配置** を要求する。

| ボーナス | 条件 | 効果 |
|---|---|---|
| **連鎖ボーナス** | 同じ機械が隣接（横） | 隣接1つにつき処理速度 **+35%** |
| **工程ボーナス** | 1レーンが正しい工程順で埋まる | そのレーンの産出価値 **+80%** |

- 連鎖を取りに行くと「プレス3つ横並び」のような配置になり、工程が崩れる
- 工程を取りに行くと縦に `プレス/縫製/梱包/―` と並び、横の連鎖が消える
- レーンは3本あるので、**「速度重視のレーン」と「価値重視のレーン」を分ける**
  ハイブリッド解が存在する。これを見つけた瞬間がこのステージのピーク

スキル S2-D3「設計図」で配置を3パターン保存でき、
「残業中だけ速度型に切り替える」といった運用が生まれる。

### 詰まり（手動介入の唯一の理由）

あるスロットの処理待ちが **3個** を超えると詰まり、そのレーンの上流が停止する。

- 詰まった箇所を **タップで即解消**、かつ溜まっていた分が一括処理されてボーナス
- S2-C3「整備工」で自動解消（3秒後）、S2-C4 で1秒
- **S2-D4「過積載」を取ると、わざと詰まらせてから解消する戦術が成立する**
  （詰まり量に比例した大量ボーナス）。自動化を「あえて切る」上級プレイ

### 残業とノルマ

| 要素 | 内容 |
|---|---|
| 残業 | 30秒間、全ライン速度 ×3。CD 5分（S2-B4 で 2分） |
| ノルマ | 5分ごとに「完成品 N 個」。達成で作業票ボーナス。**未達のペナルティは無し** |

ノルマは「今の配置で捌けるか」を測るベンチマークとして機能する。
S2-D5 でノルマ内容を3択から選べるようになり、自分の配置に合わせて選べる。

### フェーズ体験

| フェーズ | プレイヤーは何をしているか |
|---|---|
| P0 0〜2分 | 素材を手動投入。プレスを1つ置いて 12倍を体感する |
| P1 2〜6分 | 縫製を足す。144倍。自動投入（S2-C1）を買う |
| P2 6〜12分 | 梱包まで繋がる。詰まりに悩まされ、整備工を買う |
| P3 12〜20分 | レーン数が4に。連鎖と工程のどちらを取るか初めて真剣に悩む |
| P4 20〜28分 | 精密品が解放。1個 20,736枚。配置を組み直す |
| P5 28〜35分 | 6レーン全埋めで共鳴（S2-D6 ×3）。100万到達 |

### クリア後の遊び方

- **配置の最適解探し**が無限に続く。6レーン×4スロット＝24枠の組み合わせ最適化
- 機械Lv の反復購入（`1.15^n`）で CPS を伸ばし、継承ノードを買う
- 「1分間の最高産出」の自己ベスト更新が実績になる

### この棟の継承先
→ **自動化と放置効率**。以降の棟の自動化速度とオフライン上限を伸ばす。

## 3.3 ステージ3：食堂棟 ／ 通貨「チップ（枚）」

> **一言でいうと**: 賭場の期待値はプラスに設定されている。振れば振るほど増える。
> ただし大きく賭けるほど胴元が warming up し、盤面そのものが不利になっていく。

### 画面構成

```
┌────────────────────────────┐
│  🎰 48,200枚   [█░░░░░░] 100万 │
├────────────────────────────┤
│   ボッソの疑念  [███░░░░] 42%  │ ← 高いほど出目が悪くなる
│                            │
│        ⚄  ⚂  ⚅            │ ← サイコロ（スワイプで投擲）
│                            │
│     LAST: +8,400 枚         │
│   ✋ イカサマ  [██████░] 87%   │
├────────────────────────────┤
│  ベット率  2% ──●───── 8%    │ ← スライダー（所持額に対する割合）
│  ベット額  3,856枚           │
│        [  振 る  ]          │
├────────────────────────────┤
│ ◀ スクラッチ  サイコロ  ハイロー ▶ │ ← 左右スワイプでサブゲーム切替
├────────────────────────────┤
│  [棟] [ツリー] [図鑑] [設定]   │
└────────────────────────────┘
```

### コアミニゲーム「配給サイコロ」

**ベットは所持額に対する割合で指定する。** 額ではなく率。
これにより **破産が原理的に起こらない**（R-10 を数学的に保証する）。

| 出目 | 配当 | 確率（疑念 0%） |
|---|---|---|
| 1 | 0倍（没収） | 1/6 |
| 2 | 0倍（没収） | 1/6 |
| 3 | 0.5倍 | 1/6 |
| 4 | 1.5倍 | 1/6 |
| 5 | 2.0倍 | 1/6 |
| 6 | 3.5倍 | 1/6 |

```
期待値 = (0 + 0 + 0.5 + 1.5 + 2.0 + 3.5) / 6 = 1.25倍
1回あたりの成長率 r = (1.25 − 1) × ベット率 p = 0.25p
所持額は 1回振るごとに ×(1 + r)
```

**このステージの正体は複利である。** 目標までの投擲回数は対数で決まる:

```
必要投擲回数 N = ln(目標額 / 現在額) ÷ ln(1 + 0.25p)
```

| ベット率 p | 1回の成長 | 1,000 → 175万 に必要な回数 | 自動(3秒/回) | 手動(1秒/回) |
|---|---|---|---|---|
| 2%（初期） | +0.5% | 約 1,500回 | 75分 | 25分 |
| 3%（S3-A1） | +0.75% | 約 1,000回 | 50分 | 17分 |
| 5%（S3-A4） | +1.25% | 約 600回 | 30分 | 10分 |
| 8%（S3-A6） | +2.0% | 約 380回 | 19分 | 6分 |

ベット率を上げるスキルが、そのまま **時間を買うスキル** になる。
数字が指数で増えるゲームで、プレイヤーが「指数の肩」を直接いじれる唯一のステージ。

### 疑念値（このステージの中核ジレンマ）

ベット率を上げれば速いなら、常に最大で振ればいい ―― それを壊すのが **疑念値**。

```
疑念値の上昇 = (ベット率 p − 2%) × 0.8 ポイント / 投擲
イカサマ使用時 = +15 ポイント
自然減衰 = −1.5 ポイント / 秒（S3-D4 で −4.0）
```

疑念値が高いほど **出目の分布そのものが歪む**（1・2 の重みが増す）。

| 疑念値 | 実効期待値 | プレイヤーの体感 |
|---|---|---|
| 0% | 1.25倍 | 気持ちよく増える |
| 50% | 1.10倍 | まだ増えるが遅い |
| 80% | 1.00倍 | 増えも減りもしない（完全な時間の無駄） |
| 100% | 0.95倍 | **振るほど減る** |

> **プレイヤーの意思決定**: 「8%で一気に回して、疑念が溜まったら 2% に落として冷ます」
> という **アクセルとブレーキのリズム**。これがステージ3の手触りそのものになる。
> 自動投擲（S3-C3）は率が固定なので、手動プレイヤーの方が常に速い（FR-12 の担保）。

### イカサマ

投擲を重ねるとゲージが溜まり、満タンで **次の1回の出目を選べる**。

- 当然 6（3.5倍）を選ぶ。最大ベット率と合わせるのが最適
- ただし **疑念値 +15**。使うほど盤面が悪くなる
- S3-D6「完全支配」は疑念値を最大固定する代わりにイカサマ常時発動
  ＝ 実効期待値 0.95 × 出目6固定 = 3.325倍。**最終形として成立する**

### サブゲーム（左右スワイプで切替）

| サブゲーム | 役割 | 解放 |
|---|---|---|
| スクラッチ券 | 9マスを指で削る。3つ揃いで配当。**疑念値が上がらない** 安全な稼ぎ | 序盤 |
| パンくじ | 一定時間ごとに1回無料。復帰導線 | 序盤 |
| 賭けパン相撲 | オッズ付きの二者択一。観察でオッズの歪みが読める | 中盤 |
| ハイ＆ロー | 連勝で倍率が乗る。降りるか続けるかの単純な選択 | 終盤 |

**スクラッチ券は疑念を冷ましている間の受け皿**。
「サイコロで飛ばす → 疑念が溜まる → スクラッチで稼ぎながら冷ます」
という二層のループが生まれる。

### 下振れ救済

分散が大きいステージなので、表示しない救済を入れる（05章 5.6）:
- 5連敗（0倍が5回）で次回の期待値 +50%
- 「5%で大当たり」系は20回以内に必ず1回

### フェーズ体験

| フェーズ | プレイヤーは何をしているか |
|---|---|
| P0 0〜2分 | スクラッチを削る。初期チップを作る |
| P1 2〜6分 | サイコロを覚える。2%で振り続ける。複利に気づく |
| P2 6〜12分 | S3-C3 で自動投擲。放置が成立する |
| P3 12〜20分 | ベット率 5%。疑念値に初めて殴られる。冷ます動きを覚える |
| P4 20〜28分 | イカサマを絡める。アクセルとブレーキのリズムが完成 |
| P5 28〜40分 | 8%で回し切る。桁が一気に飛ぶ。100万到達 |

### クリア後の遊び方

- **5棟中もっとも放置効率が高い棟**。自動投擲を回しっぱなしにできる
- 疑念値の自然減衰（S3-D4）を取っていれば、無人でも安定して増え続ける
- 継承ノード（最大5億）を貯める主力拠点になりやすい

### この棟の継承先
→ **確率と運の底上げ**。以降の棟のランダム判定・ブースト効果を強化する。

## 3.4 ステージ4：医務棟 ／ 通貨「錠剤（錠）」

> **一言でいうと**: 錠剤が勝手に湧く盤面。同じものを2つくっつけると1ランク上になる。
> 育てるほど価値は跳ね上がるが、盤面が埋まると何も湧かなくなる。

### 画面構成

```
┌────────────────────────────┐
│  💊 312,400錠  [███░░░░] 100万 │
├────────────────────────────┤
│  ┌──┬──┬──┬──┬──┐         │
│  │R3│R3│R1│R5│R2│         │
│  ├──┼──┼──┼──┼──┤         │
│  │R1│R4│R4│R1│R7│         │
│  ├──┼──┼──┼──┼──┤         │
│  │R2│R1│▨ │R2│R1│ ← ▨=汚染タイル │
│  ├──┼──┼──┼──┼──┤         │
│  │R6│R1│R1│R3│R3│         │
│  ├──┼──┼──┼──┼──┤         │
│  │R1│R2│R1│R1│R4│         │
│  ├──┼──┼──┼──┼──┤         │
│  │R1│R1│R5│R1│R2│         │
│  └──┴──┴──┴──┴──┘         │
│  ▼▼▼  投 薬 口  ▼▼▼          │ ← ドラッグで換金
├────────────────────────────┤
│ 処方箋: R7を2つ納品  [報酬 ×12] │
├────────────────────────────┤
│  [棟] [ツリー] [図鑑] [設定]   │
└────────────────────────────┘
```

### コアミニゲーム「調合台」

5×6 のグリッド。空きマスに **1.5秒ごとに R1 の錠剤が湧く**。
同ランクの錠剤を隣接させてドラッグすると合成され、1ランク上になる。

```
ランク R の価値 v(R) = 3^(R−1)
R(n) を1個作るのに必要な R1 = 2^(n−1) 個
→ 投入した R1 あたりの価値 = (3/2)^(n−1)
```

| ランク | 価値 | 必要 R1 | R1 あたり効率 |
|---|---|---|---|
| R1 | 1 | 1 | ×1.0 |
| R3 | 9 | 4 | ×2.3 |
| R5 | 81 | 16 | ×5.1 |
| R7 | 729 | 64 | ×11.4 |
| R10 | 19,683 | 512 | ×38.4 |
| R12 | 177,147 | 2,048 | ×86.5 |

**育てるほど効率が良い。** ならば常に最高ランクまで育てればいい ―― それを壊すのが盤面。

### 在庫回転のジレンマ（このステージの中核）

```
盤面が満杯になると、新規生成が完全に停止する
```

- 育てるには R1 を 512個 集める必要があり、その間ずっと盤面を占有する
- 占有すると生成が止まり、**単位時間あたりの産出がゼロに近づく**
- かといって R1 のまま売れば効率 ×1.0

つまりこれは **在庫回転率と単価の古典的なトレードオフ** である。

> **プレイヤーの意思決定**: 「R5 で切って回転を上げるか、R8 まで我慢するか」
> 盤面の空きマス数を見ながら、売るランクの閾値を常に調整し続ける。
> 自動換金（S4-C2）は **この閾値を数値で設定する機能** ＝
> プレイヤーの判断をそのまま自動化に翻訳できる、良い自動化の形。

### 副作用（高効率のコスト）

**R7 以上を換金すると 15% の確率で汚染タイルが発生**し、
そのマスが 40秒間使用不能になる（生成も合成も不可）。

- 高ランク戦略を取るほど盤面が削られ、回転がさらに落ちる
- S4-D1 で発生率 −30%、S4-D2 でタップ即除去
- **S4-D4「副作用の利用」で、汚染の代わりに全換金額 ×2（20秒）に変換できる**
  ＝ デメリットをメリットに反転させる、このステージの転換点スキル

### 処方箋（目標を与える仕組み）

「R7 を2つ納品」等の注文が常時1〜3件（S4-D3）。
達成すると大量の錠剤＋**恒久的な生成速度上昇**。

放っておくと「何ランクまで育てるか」が曖昧になりがちなステージなので、
処方箋が **今日の目標** を外から与える役割を持つ。

### 自動化の段階

| スキル | 効果 |
|---|---|
| S4-C2 換金ライン | 指定ランク以下を自動換金（＝閾値の自動化） |
| S4-C3 合成アーム | 隣接する同ランクを自動合成（手動の 1/3 速度） |
| S4-C5 最適化アーム | 最高ランク優先で合成 |
| S4-C6 全自動調剤 | アーム速度が手動と同等に |

手動の方が速い状態が長く続くため、**5棟でもっとも「触っていたくなる」棟**。

### フェーズ体験

| フェーズ | プレイヤーは何をしているか |
|---|---|
| P0 0〜2分 | 指でくっつける。R3 を作って換金 |
| P1 2〜6分 | R5 が見えてくる。盤面が埋まり始めて焦る |
| P2 6〜12分 | 自動換金の閾値設定を覚える。盤面が回り出す |
| P3 12〜20分 | 盤面拡張（6×6）。R7 に初到達。汚染タイルに殴られる |
| P4 20〜28分 | 合成アームで半自動化。処方箋を軸に回す |
| P5 28〜45分 | R10 到達。1個 19,683錠。連鎖合成で盤面が生き物のように動く |

### クリア後の遊び方

- **最高ランク更新**が明確な目標になる（R12 → R15 → …）
- カルテ（図鑑）の全ランク登録と、S4-D5「カルテ特典」（登録数 ×2%）
- S4-D6「劇薬」で盤面を全消去して一括換金する、リセット型の遊び

### この棟の継承先
→ **効率と倍率の底上げ**。以降の棟の乗算系ボーナスとブースト持続を強化する。

## 3.5 ステージ5：中央塔 ／ 通貨「金塊（g）」

> **一言でいうと**: 4つの階が縦に繋がった1本の工場。
> 1〜4棟の遊びが小型化して各階に入り、どこか1つでも詰まると全体が止まる。

### 画面構成

```
┌────────────────────────────┐
│  🪙 620,000g  [████░░░] 100万 │
├────────────────────────────┤
│ 3F 金庫   [鋳造]  ██████ 1,240/分│
│    ▲ 延べ棒 ×48                │
│ 2F 兌換   [相場]  ███░░░  620/分 │ ← 赤＝ボトルネック
│    ▲ 延べ棒 ×210               │
│ 1F 精錬   [炉]    ████░░ 1,800/分│
│    ▲ 鉱石 ×1,420               │
│ B1 採掘   [壁]    ██████ 3,100/分│
├────────────────────────────┤
│  ⚡共鳴 [███░░] Lv差 5 / 3 以内  │
├────────────────────────────┤
│  [棟] [ツリー] [図鑑] [設定]   │
└────────────────────────────┘
```

### 構造：直列パイプライン

```
B1 採掘 ──鉱石──▶ 1F 精錬 ──延べ棒──▶ 2F 兌換 ──延べ棒──▶ 3F 金庫 ──▶ 金塊
 (S1型)            (S2型)              (S3型)               (S4型)
```

```
全体のスループット = min(B1, 1F, 2F, 3F)
```

**このステージの正体は、最小律（リービッヒの樽）である。**
一番弱い階だけが全体の産出を決める。他の階をいくら伸ばしても1gも増えない。

> **プレイヤーの意思決定**: 「どの階が詰まっているか」を見て、**そこにだけ投資する**。
> 画面は各階のスループットをバーで表示し、最小の階を赤く塗る。
> 「赤いところを直す」だけの、極めて明快で中毒性のあるループになる。

### 各階の中身（1〜4棟の再登場）

| 階 | 元ネタ | 中身 | 手動介入 |
|---|---|---|---|
| B1 採掘 | S1 クリッカー | 岩盤をタップして鉱石。層構造も踏襲 | タップで一時的に産出 ×3 |
| 1F 精錬 | S2 ライン | 炉に鉱石を流す。炉の配置と連鎖 | 詰まり解消 |
| 2F 兌換 | S3 賭博 | 延べ棒の相場が変動。安く買い高く売る | 売買タイミング |
| 3F 金庫 | S4 マージ | 延べ棒を合成して金塊に鋳造 | ドラッグ合成 |

**重要**: 各階は前の棟の「簡略版」であり、**新しい操作を一切覚えなくていい**。
最終ステージの認知負荷はゼロで、純粋に「全体最適」だけに集中できる。

### 2F 兌換の相場

延べ棒の兌換レートが 30秒周期で 0.6倍 〜 1.8倍 を振動する。

- S5-C1 で変動が可視化され、S5-C3 で指値（自動売買）
- S5-C5「内部情報」で次の変動を5秒前に予告
- S5-C6「相場操縦」でレートを1回だけ任意の値に固定（CD 2分）

ステージ3ほど複利は効かないが、**ボトルネックが 2F のときだけ手動で稼げる**
という、パイプラインの中に置かれた小さな賭場として機能する。

### 共鳴（Fortune Mill 的シナジーの最終形）

```
4階すべての Lv 差が 3 以内 → 全産出 ×2（S5-D5 で ×3）
隣接する階のスキルは、互いに 30%（S5-D4 で 50%）の効果で波及する
```

- 「1階だけ伸ばす」が構造的に損になる。最小律と共鳴が **同じ方向を指している**
- S5-D4 の解放条件を「B1・1F・2F の自動化を全て所持」にして、
  全階に触れないと最深部に進めないようにする

### 終盤演出

所持金塊が 80万 を超えると、所長ヴァレンが監視カメラ越しに話しかけ始める。
100万で【賄賂】ノードが点灯し、購入すると門の解錠シーケンス → エンディング。

### クリア後の遊び方

- **エンディング後も中央塔は動き続ける**（R-05）。共鳴を維持したまま CPS を伸ばす
- 5棟すべての密輸ルート（L4）を開通させると、4棟からの流入が中央塔に集まる
- NG+（Lethal モード）のタイムアタック対象は主にこの棟

### この棟の継承先
→ **全体倍率と密輸ルートの強化**、および NG+ / 続編への接続（04章 S5-L4）。

## 3.6 ステージ設計の共通チェックリスト

新ステージを追加・調整する際は以下を満たすこと。

- [ ] 開始 30秒以内に、手動操作だけで最初の通貨を獲得できる
- [ ] プレイ時間の 25〜35% 地点で最初の自動化に到達する
- [ ] 手動プレイの効率は自動の 3〜5倍を保つ（放置を上位互換にしない）
- [ ] 「桁が上がる瞬間」が 5回以上ある（1 → 10 → … → 1,000,000）
- [ ] **「常に最大でやればいい」を壊す対抗ギミックが必ず1つある**
      （S1=コンボ切れ / S2=連鎖と工程の相反 / S3=疑念値 / S4=盤面の有限性 / S5=最小律）
- [ ] 最後の 10分は「溜めた仕組みが一気に回る」爽快フェーズである
- [ ] **クリア後に無限に伸ばせる反復購入要素があり、継承ツリーの資金源になる**
