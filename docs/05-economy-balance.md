# 05. 経済バランス

## 5.1 基本方程式

1ステージの収支は次の 3 数値で定義される。

| 記号 | 意味 | 値 |
|---|---|---|
| `GOAL` | 賄賂に必要な所持額 | **1,000,000** |
| `TREE` | スキルツリー総額（24ノード） | **750,000** |
| `LIFE` | 標準ルートの生涯獲得額 | **約 1,750,000** |

`LIFE = GOAL + TREE` が基本だが、T6 ノード（150,000 × 4）は全買いを前提にしない。
T6 を 0個買う最速ルートなら `LIFE ≈ 1,150,000`、4個全買いなら `LIFE ≈ 1,750,000`。
**どちらでもクリアできる** ことがバランスの合格ラインである。

## 5.2 成長曲線（全ステージ共通テンプレート）

標準プレイヤー（手動と放置を半々）における、1ステージの進行モデル。

| フェーズ | 名称 | 経過時間 | この時点の累計獲得 | 平均収入 | プレイヤーの行動 |
|---|---|---|---|---|---|
| P0 | 徒手空拳 | 0〜2分 | 200 | 約 1.7 /秒 | 手動のみ。T1 を1〜2個買う |
| P1 | 最初の他人 | 2〜6分 | 2,000〜3,000 | 約 12 /秒 | 自動収入が動き出す。T2 を揃える |
| P2 | 自動化到達 | 6〜12分 | 20,000 | 約 47 /秒 | **T3（オート系）を購入**。放置が成立 |
| P3 | 倍率の発見 | 12〜20分 | 120,000 | 約 208 /秒 | T4 で全体倍率。数字の単位が変わる |
| P4 | 複利 | 20〜28分 | 500,000 | 約 790 /秒 | T5。自動と手動が噛み合う |
| P5 | 爆発 | 28〜35分 | 1,750,000 | 約 2,980 /秒 | T6 を取捨選択し、GOAL へ到達 |

- 各フェーズで **平均収入が約 4〜7倍** になる。これが「桁が上がる快感」の実体
- 最終 CPS はおよそ **5,000 /秒**。GOAL の 1,000,000 は最後の 3〜4分で積み上がる
- 放置のみのプレイヤーは所要時間が **約 2.5倍**（1ステージ 80〜90分）になるが、必ず到達する

|---|---|---|---|---|
| 1 | 独房棟 | 25分 | 60分 | チュートリアル込みで最短 |
| 2 | 労役棟 | 35分 | 70分 | 配置を考える時間を含む |

## 5.4 コスト式

### スキルノード
段階固定（04章のコスト階梯）。**同一ノードの再購入は無し**（1回買い切り）。

### 反復購入型アイテム（子分・機械Lv・採掘スロット等）
```
cost(n) = base × 1.15^n     ( n = 既購入数 )
```
- `1.15` は Cookie Clicker 系の標準値。購入間隔が体感的に心地よい
- 一括購入ボタン（×1 / ×10 / ×最大）を必ず用意する（NFR-04）

### 収入の合成規則
```
収入 = 基礎値
     × (1 + Σ 加算系ボーナス)      ← 同種のボーナスは加算
     × Π 乗算系ボーナス            ← 種類の違うボーナスは乗算
     × 一時ブースト
     × 人脈ボーナス
```
- 加算と乗算を明確に分けて表示する。プレイヤーが「次にどれを買うと伸びるか」を
  自力で計算できることがインクリメンタルの根幹

## 5.5 オフライン進行

```
オフライン獲得 = 自動収入(CPS) × min(経過秒, 上限秒) × 0.60 × 人脈補正
上限秒 = 28,800（8時間）+ 人脈ボーナス（最大 +7,200）
```
- 手動由来の収入（タップ・ミニゲーム）は **一切含まない**
- 広告視聴で「留守中の稼ぎ ×2」を 1日3回まで（任意機能）
- 復帰ダイアログには **経過時間 / 獲得額 / 現在CPS** の3つのみを表示する

## 5.6 乱数の扱い

| ルール | 内容 |
|---|---|
| 疑似乱数の分布保証 | 「5%で大当たり」は **20回以内に必ず1回** 出る補正付き（pity system） |
| 連敗の緩和 | ステージ3のサイコロは 5連敗で次回の期待値を +50%（表示はしない） |
| リプレイ性 | 乱数シードは端末ローカル。セーブのロード＆リトライによる粘りは防がない（シングルプレイのため） |
| 表示の誠実さ | 表示している確率と内部確率を一致させる（pity は「下振れ救済」方向にのみ働く） |

## 5.7 数値の表示規則

| 範囲 | 表示 |
|---|---|
| 〜9,999 | `8,240` |
| 10,000〜99,999,999 | `1.2万` / `34.5万` / `1,000万` |
| 100,000,000〜 | `1.2億`（NG+ 以降でのみ到達しうる） |
| 秒間収入 | `+1,240 /秒` |

- **目標額は常に `100万` と表記**（`1,000,000` と併記しない）。「100万」がゲーム全体の合言葉
- 所持額は画面上部に固定表示し、GOAL に対する **プログレスバー** を常に添える

## 5.8 バランス調整の原則

1. **手動 > 自動** を常に維持（手動は自動の 3〜5倍）。放置は「進むが最速ではない」
2. **どのスキルを買っても前進する**。罠ノード（買うと損する）は作らない
3. **上限を作らない**。GOAL 到達後も数値は伸び続ける（実績・記録のため）
4. **待ち時間の最大値は 90秒**。これを超える待機を強制するギミックは作らない
5. **1ステージ 40分**。これを大きく超える場合はステージ側の数値ではなく
   **フェーズ構成** を見直す（フェーズが多すぎる＝ギミックの入れすぎ）
