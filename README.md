# PRISON DEBT（仮題） — 脱獄インクリメンタルゲーム

多額の借金で投獄された主人公が、5つの牢屋で 100万 を稼ぎ、看守に賄賂を渡して
外へ出るまでを描く、スマートフォン向けインクリメンタル／放置ゲームです。

参考タイトル: [Fortune Mill](https://store.steampowered.com/app/4731620/Fortune_Mill/)
（部屋ごとに異なるミニゲームで $1,000,000 を稼ぎ脱出するインクリメンタル）を
スマホ・**横持ち・両手操作**に再設計し、独自のストーリーとステージ構成を与えたもの。

## 一行で言うと

> 「稼ぐ → 強くなる → もっと稼ぐ」を 5 回繰り返す。ただし毎回ルールも通貨も変わる。
> 看守への賄賂はスキルツリーの最終ノードで、その先には次の牢屋を強くする枝が伸びている。
> だから前の牢屋には、何度でも戻ることになる。
> 出口の先には 6 つ目の牢屋が待っていて、そこで全てを失い、また最初の牢屋から始める。
> ――積み上げたものを全部捨てて、時計と戦う場所も、別にある。

## 3つの層

| 層 | 何が伸びるか | リセット |
|---|---|---|
| ステージ内 | 本編ツリー T1〜T6 と【賄賂】T7 | 周回でリセット |
| 周の中 | 継承ツリー L1〜L4、密輸ルート | 周回でリセット |
| 周をまたぐ | **永久スキル表**（脱獄章で購入） | されない |
| （別軸） | **ハードモード「死線」** — 上の3層を全て無効化し、制限時間を課す | ― |
